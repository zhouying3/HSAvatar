# HSAvatar

Project page: https://zhouying3.github.io/HSAvatar/

One-shot Animatable Gaussian Avatars via an Adaptive Hybrid Shape Model and UVH-guided Appearance Modeling.

The static page presents pre-rendered FLAME control, avatar and HSM shape animation, audio and image driving examples, and continuous reconstruction videos with matched RGB error comparisons. It does not require a rendering server. RTX 4090 timing data and measurement scopes are provided in `assets/showcase/benchmark.json`.

The reconstruction section provides synchronized ROME/HSAvatar comparisons, RGB error and reconstruction views, per-frame seeking, playback speed, and original-size viewing. Every sequence contains 50 matched frames. Sequence and per-frame RGB MAE use a shared reference foreground and fixed color scale.
